# دليل الزائر — Native Android — المرحلة الثالثة

هذه المرحلة تكمل الانتقال إلى Native Android فوق مصدر Flutter الأصلي الموجود في `migration_source`، مع عدم استبدال المحتوى الديني بمحتوى خارجي.

## ما تم إدخاله في المرحلة الثالثة
- محرك Routing Native يعتمد بيانات OSRM الأصلية المستخدمة في مشروع Flutter.
- دعم حفظ المسارات محليًا لاستخدامها لاحقًا بدون اتصال.
- تخزين بلاطات OSM محليًا مع مسار احتياطي مطابق لخدمة الخرائط الأصلية.
- محرك خرائط Native باستخدام osmdroid مع وضع Online وOffline.
- عارض PDF Native لملف `ahilla.pdf` الموجود داخل المشروع.
- الإبقاء على بيانات المشروع الأصلية داخل `migration_source` وعدم استبدالها بمحتوى ديني خارجي.
- استمرار استخدام حاسبة مواقيت الصلاة الشيعية والبيانات الأصلية للمراقد والمدن والمحتوى.
- تسجيل الأنشطة Native الجديدة في Manifest وتجهيز الصلاحيات اللازمة.

## المحتوى الذي يبقى مصدره المشروع
القرآن ومفاتيح الجنان والصحيفة السجادية وملفات الأدعية والزيارات والبيانات المتعلقة بالمراقد والأهلة وقضاء الصلاة وغيرها يجب أن تبقى مرتبطة بمصادر المشروع الأصلية. لا يتم إدخال نصوص دينية جديدة من خارج المصدر لمجرد ملء الواجهات.

## ملاحظة الاختبار
بعد هذه المرحلة يجب تشغيل `gradle :app:assembleDebug` ومراجعة أخطاء Kotlin/Gradle أولًا، ثم اختبار الخرائط Online/Offline وفتح PDF وحفظ المسارات على الجهاز قبل الانتقال إلى اختبار الوظائف الأخرى.
