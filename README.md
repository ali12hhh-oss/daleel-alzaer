# دليل الزائر — Native Android — المرحلة الثانية

هذه المرحلة تبني وظائف حقيقية فوق أساس المرحلة الأولى، مع إبقاء مصدر Flutter داخل `migration_source` كمرجع.

## ما أضيف في المرحلة الثانية
- ربط محتوى مفاتيح الجنان والصحيفة السجادية من ملفات JSON المحلية.
- شاشة قراءة تفصيلية للمحتوى مع RTL وتمرير مريح.
- شاشة الكتب مع الحفاظ على ملف PDF ضمن assets للربط في مرحلة عارض PDF.
- عداد التسبيح مع حفظ العداد أثناء إعادة إنشاء الشاشة.
- إعدادات أساسية للوضع الليلي والإعدادات المتعلقة بالموقع والإشعارات.
- طلب صلاحية الموقع وقت الحاجة فقط.
- حساب مسافة جغرافية حقيقية من الموقع الحالي إلى مرقد الإمام الحسين (ع).
- حساب السمت الجغرافي الحقيقي من الموقع الحالي إلى مكة كخطوة أولى للقبلة.
- فتح الوجهة في خرائط Google عبر Intent.
- إصلاح Manifest وإضافة Compose Compiler Plugin المطلوب لـ Kotlin 2.
- استمرار تأثير التموج المائي في الأزرار والبطاقات.

## ما لم يتم ادعاؤه كجاهز
- محرك Routing الفعلي.
- تنزيل/تخزين Offline Tiles.
- حساس دوران الهاتف للقبلة بشكل كامل.
- حساب أوقات الصلاة النهائية والإشعارات والأذان.
- عارض PDF Native.

هذه الأجزاء ستدخل في المرحلة الثالثة/مرحلة الاختبار حتى لا نضع بيانات أو مسارات وهمية داخل التطبيق.
