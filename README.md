# دليل الزائر

تطبيق Android أصلي جديد مبني من الصفر بـ Kotlin + Jetpack Compose.

## المبدأ
هذا المشروع لا يعتمد على كود التطبيق السابق. الفكرة والوظائف العامة مستوحاة من هدف التطبيق، لكن البنية والتنفيذ جديدان ومستقلان.

## الوحدات الأساسية
- الصفحة الرئيسية ولوحة الوصول السريع
- مواقيت الصلاة
- القرآن الكريم مع تحميل السورة عند الطلب
- القبلة وتحديد الموقع
- قائمة المراقد والمواقع وفتح الطريق في خرائط Google
- الملاحة
- المسبحة مع حفظ العداد محلياً
- قضاء الصلاة مع حفظ الأعداد
- الأدعية والزيارات
- الإعدادات والوضع الليلي وحجم الخط

## خطة التطوير
كل وحدة ستُستكمل وتُختبر مستقلة، ثم تُربط بالواجهة الرئيسية. نجاح Gradle وحده لا يُعتبر اكتمالاً للميزة.
